# 하루가나 · 일본어 첫걸음 (v6 · 사쿠라 테마 · 캐릭터 목소리)

히라가나·가타카나 208자와 JLPT N5 단어 409개를 소리로 듣고,
플래시카드와 퀴즈로 외우는 왕초보용 앱이에요. 휴대폰 홈 화면에 설치할 수 있는 웹앱(PWA)입니다.

## 화면과 기능

| 탭 | 하는 일 |
|---|---|
| **홈** | 연속 공부일수, 오늘의 목표, **오늘의 복습**, **공부 순서**(히라가나 → 가타카나 → 탁음·요음 → N5 단어), 오늘의 글자·단어, 유튜브 추천 강의 |
| **글자표** | 히라가나/가타카나 표. 누르면 소리가 나요. **헷갈리는 글자**(シ/ツ, ぬ/め 등) 비교와 구별 요령 |
| **단어장** | N5 단어 409개. 검색(일본어·한글·로마자), 주제별 보기, ★ 즐겨찾기, **"한국어와 비슷해요"** 표시 98개 |
| **연습** | 플래시카드, 퀴즈 (글자 / 단어), **쓰기 연습** |
| **기록** | 복습 일정, 공부 도장 달력, 최근 7일 그래프, 외운 것, 자주 틀리는 것, 설정, 백업 |

### 퀴즈 방식
- 글자: 읽는 법 고르기 · 읽는 법 쓰기(한글/로마자) · 글자 고르기 · 듣고 고르기
- 단어: 뜻 고르기 · 단어 고르기 · 듣고 뜻 고르기
- 틀린 것은 더 자주 나와요. 헷갈리는 글자는 오답 보기로 일부러 섞여 나와요.

### 오늘의 복습 (간격 반복)
카드에서 "외웠어요"를 누르거나 퀴즈에서 맞히면 **1일 → 3일 → 7일 → 14일 → 30일** 뒤에 다시 복습하도록
일정이 자동으로 잡혀요. 틀리면 처음부터 다시 시작해요. 홈의 "오늘의 복습"에서 한 번에 복습할 수 있어요.

### 쓰기 연습
- **따라 쓰기**: 흐린 글자 위에 손가락이나 S펜으로 덧써요.
- **보지 않고 쓰기**: 읽는 법만 보고 쓴 뒤 "정답 보기"로 비교해요.
- S펜은 누르는 힘에 따라 선 굵기가 달라지고, 펜으로 쓰는 동안 손바닥 터치는 무시해요.

### 발음 규칙 미니 강의
모음, 탁음, 반탁음, 요음, 촉음(작은 っ), 장음, ん, 조사 は·へ·を를 쉬운 설명과
눌러서 듣는 예시로 정리했어요. (예: びょういん 병원 vs びよういん 미용실)

### 편의 기능
- 플래시카드를 옆으로 밀기 (→ 외웠어요, ← 아직 몰라요)
- PC 단축키: 카드(스페이스 뒤집기, ←/→), 퀴즈(숫자 1~4, Enter)
- 정답·오답 효과음, 진동, 목소리 고르기, 말하는 빠르기
- 단어의 한글 발음과 로마자를 자동으로 만들어 보여줘요 (예: がっこう → 갓코우 · gakkou)
- 기록 백업/불러오기 (파일), 다크 모드, 홈 화면 설치 버튼, 새 버전 알림

## 캐릭터 목소리 (VOICEVOX:冥鳴ひまり)
- 글자 208자(가타카나는 같은 소리 파일 사용), 단어 409개, 발음 강의 예시를 **VOICEVOX의 冥鳴ひまり(메이메이 히마리)** 목소리로 미리 만들어 `audio/` 폴더에 넣었어요.
- 앱은 소리 파일이 있으면 그걸 재생하고, 없으면 휴대폰 음성(TTS)으로 읽어요.
- **기록 › 설정 › 소리**에서 "캐릭터 목소리 쓰기"를 끄면 휴대폰 음성으로 바뀌어요.
- "인터넷 없이 듣도록 미리 받기"를 누르면 모든 소리를 기기에 저장해요. 누르지 않아도 한 번 들은 소리는 자동으로 저장돼요.
- 이용 조건: 「VOICEVOX:冥鳴ひまり」 출처를 표시하면 상업·비상업 모두 사용할 수 있어요. 자세한 내용은 `audio/POLICY.md`와
  https://meimeihimari.wixsite.com/himari/terms-of-use 를 봐 주세요.
- 다른 캐릭터로 바꾸고 싶으면 VOICEVOX로 같은 이름의 파일을 다시 만들어 `audio/` 폴더를 바꾸면 돼요.

## 갤럭시 S26 울트라 · 갤럭시 탭 S9+
- 두 기기에 맞춰 화면을 맞췄어요. 탭은 **세로·가로 모두** 쓸 수 있고, 넓은 화면에서는 2단으로 보여요.
- **삼성 인터넷**과 **크롬** 모두 돼요.
  - 크롬: 홈 화면의 "설치" 버튼, 또는 메뉴(⋮) › 홈 화면에 추가
  - 삼성 인터넷: 아래쪽 메뉴(≡) › 현재 페이지 추가 › 홈 화면
- 소리가 안 나면: 설정 › 일반 › 텍스트 음성 변환(TTS) › 기본 엔진 옆 ⚙ › 음성 데이터 설치에서 **일본어**를 내려받아요.
  (One UI 버전에 따라 메뉴 이름이 조금 다를 수 있어요)
- 휴대폰에 설치하려면 앱이 https 주소로 인터넷에 올라가 있어야 해요 (GitHub Pages 등).

## PC에서 실행하기

> ⚠️ `index.html`을 더블클릭해서 열어도 화면은 나오지만, **오프라인 실행과 설치 기능은 동작하지 않아요.**

### 방법 1. VS Code + Live Server (가장 쉬움)
1. [VS Code](https://code.visualstudio.com/)를 설치하고 이 폴더를 열어요. (파일 › 폴더 열기)
2. 왼쪽 확장(네모 4개 아이콘)에서 **Live Server**를 검색해 설치해요.
3. `index.html`을 오른쪽 클릭 › **Open with Live Server**를 눌러요.

### 방법 2. 파이썬 (설치되어 있다면)
이 폴더에서 터미널(윈도우는 PowerShell)을 열고:
```bash
python -m http.server 8000
```
브라우저 주소창에 `http://localhost:8000` 을 입력해요. 끄려면 `Ctrl + C`.

**추천 브라우저:** 크롬 또는 엣지. F12 › 휴대폰 아이콘을 누르면 휴대폰 크기로 볼 수 있어요.

## 파일 설명
| 파일 | 역할 |
|---|---|
| `index.html` | 화면의 뼈대 |
| `style.css` | 디자인. 맨 위 `:root` 에서 색을 바꿀 수 있어요 |
| `app.js` | 동작 (소리, 카드, 퀴즈, 저장 등) |
| `kana-data.js` | 글자 목록과 읽는 법 |
| `vocab-data.js` | N5 단어 목록, 헷갈리는 글자 목록 |
| `videos-data.js` | 유튜브 추천 강의 목록 |
| `lessons-data.js` | 발음 규칙 강의 내용 |
| `audio/` | 캐릭터 목소리 소리 파일과 목록(`audio/index.js`) |
| `manifest.json`, `sw.js`, `icons/` | 홈 화면 설치 · 오프라인 실행 |

### 단어나 영상을 추가하고 싶다면
- 단어: `vocab-data.js` 에 `['単語', 'たんご', '단어', '단어', 1],` 처럼 한 줄 추가
  (4번째는 한국어 한자어, 5번째 `1`은 "한국어와 비슷해요" 표시)
- 영상: `videos-data.js` 에 `{ id: '영상ID', title: '제목', channel: '채널' },` 한 줄 추가
- 추가한 뒤 `sw.js` 맨 위 `VERSION` 숫자를 올려 주세요. (예: `harukana-v7`)

## 고친 내용이 반영되지 않을 때
서비스 워커가 옛 파일을 저장해 두고 있어서 그래요. `sw.js`의 `VERSION`을 올리거나, 크롬에서 `Ctrl + Shift + R`.

## 기록은 어디에 저장되나요?
지금 쓰는 브라우저 안(localStorage)에만 저장돼요. 기기를 바꿀 때는 **기록 › 기록 백업 › 파일로 저장** 후
새 기기에서 **파일 불러오기**를 하면 이어서 공부할 수 있어요.
