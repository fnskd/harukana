# 마리안 웨딩 테마 키트 (Galaxy S26 Ultra)

NIKKE 마리안 웨딩 스킨 이미지로 갤럭시 테마 재료를 만드는 웹 페이지예요.
`index.html`을 휴대폰이나 PC 브라우저로 열면 돼요. (GitHub Pages가 켜져 있으면 https://fnskd.github.io/harukana/galaxy-theme/ )

## 만들어지는 것
| 파일 | 내용 |
|---|---|
| `marian-lock.png` | 잠금화면 배경 1440×3120 (면사포 빛, 파란 장미 꽃잎, 금빛 별, 레이스 테두리, 필기체 문구) |
| `marian-home.png` | 홈화면 배경 1440×3120 (아이콘이 잘 보이게 아래쪽을 흐리게, 문구 없음) |
| `icons/*.png` | 앱 아이콘 25개, 512×512 (진주 / 로즈 / 웨딩 나이트 스타일, 동그라미 / 둥근 사각형) |
| `색상표-및-적용방법.txt` | 주요색·강조색·포인트색·글자색 코드와 적용 순서 |

## 쓰는 법
1. 페이지에서 마리안 웨딩 스킨 스크린샷을 올려요. 사진은 기기 밖으로 나가지 않아요.
2. 확대·위치를 맞추고 꽃잎, 레이스, 문구를 고른 뒤 **전체 키트 받기**를 눌러요.
3. Galaxy Store → Good Lock → **Theme Park** → 테마 → 새로 만들기 → `marian-lock.png` 선택 → 색 팔레트를 색상표 코드로 바꾸고 적용.
4. Theme Park → 아이콘 → 새로 만들기 → 앱마다 `icons` 폴더의 같은 이름 사진 선택.
5. 설정 → 배경화면 및 스타일 → 홈 화면에 `marian-home.png`.

기본 색은 마리안 웨딩 스킨에 맞춘 **사파이어** (하얀 드레스, 사파이어 보석, 파란 장미, 금빛 별)이고, 블러시 핑크로도 바꿀 수 있어요.
확대를 1배보다 작게 하면 그림 전체가 들어가고, 빈 곳은 그림 가장자리 색을 흐리게 늘려 채워요 (얼굴이 시계에 가리지 않게).
사진을 올리지 않으면 직접 그린 기본 웨딩 일러스트(반지, 장미, 면사포)로 만들어져요.

## 잠금화면 영상
갤럭시 잠금화면에는 15초 이하 영상을 넣을 수 있어요. 설정 → 배경화면 및 스타일 → 배경화면 바꾸기 → 갤러리에서 영상을 고르고 잠금화면에 적용해요.

## 저작권
마리안 스킨 그림의 저작권은 게임 제작사에 있어요. 만든 테마는 개인 휴대폰에서만 쓰고 배포·판매하지 마세요.
이 키트의 기본 그림·장식·아이콘 바탕은 직접 그렸고, 아이콘 기호는 Google Material Symbols(Apache 2.0)를 써요.
