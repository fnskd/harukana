마리안 웨딩 테마 키트

하얀 드레스, 사파이어, 파란 장미, 금빛 별. 마리안 웨딩 스킨 이미지를 올리면 S26 울트라 화면 크기(1440×3120)에 맞는 잠금화면·홈화면 배경, 웨딩 색상표, 아이콘 25개를 만들어요. 만든 파일은 Good Lock의 Theme Park에 넣어 갤럭시 테마로 써요.

i.마리안 이미지

iii.웨딩 색상표

사진을 올리면 색을 자동으로 뽑아요. 색 상자를 눌러 바꿀 수 있고, 코드를 누르면 복사돼요. Theme Park에서 색을 직접 고를 때 이 코드를 넣어요.

vi.갤럭시에 적용하기

  1. Good Lock 설치 — Galaxy Store에서 Good Lock을 받고, Good Lock 안의 목록에서 Theme Park를 설치해요.
  2. 키트 풀기 — 받은 ZIP을 내 파일에서 눌러 압축을 풀어요. 사진이 갤러리에 보이게 됩니다.
  3. 테마 만들기 — Theme Park → 테마 → 새로 만들기 → marian-lock.png를 고르고 잘라내기 영역을 화면 전체로 맞춰요. Theme Park가 사진에서 색을 자동으로 뽑아요.
  4. 색 다듬기 — 편집 화면에서 색 팔레트를 눌러 위 색상표 코드로 바꿔요. 퀵패널 배경은 주요색, 버튼과 스위치는 강조색, 퀵패널 글자는 글자색이 잘 어울려요. 저장 후 적용을 눌러요.
  5. 아이콘 바꾸기 — Theme Park → 아이콘 → 새로 만들기에서 앱을 하나씩 눌러 icons 폴더의 같은 이름 사진을 골라요. 다 고르면 저장하고 적용해요.
  6. 홈화면 배경 — 테마를 적용한 뒤 설정 → 배경화면 및 스타일 → 배경화면 바꾸기에서 홈 화면에만 marian-home.png를 넣어요.
  7. 키보드·볼륨 패널 — Theme Park의 키보드와 볼륨 패널 탭에서도 같은 색상표 코드를 쓰면 전체가 한 벌로 맞춰져요.

메뉴 이름은 One UI 버전에 따라 조금 다를 수 있어요. 마리안 스킨 그림의 저작권은 게임 제작사에 있으니 만든 테마는 내 휴대폰에서만 쓰고, 다른 사람에게 배포하거나 판매하지 마세요. 이 키트의 기본 그림, 장식, 아이콘은 직접 그린 그림이라 자유롭게 써도 돼요.
